The program `manual` shows the documentation that each module carries in its file. That text is the comments of the source of the module, written in a small part of Markdown. The manual now reads the marks. A bold word is in the bold weight. A word in italics has a thin line under it, because the system has no italic face. A name of code is in the monospace font, in the color of code. A list item has its mark and its indentation. An example is a block of rows. A link is a colored name. When a link names a module of the boot image, or one of its exports, it has a line under it, and a click on it shows that page. A row ends between two words, never inside one, unless one word is longer than the row. The help that the console prints for a command is the same plain line as before.
