The console now colors the code that a person types. Functions, types, texts, numbers and punctuation each have a color, from one table of the system. The completion list colors its signatures in the same way. A name that the console does not know is marked once the person has typed past it. The chosen row of a list has a stronger background, so its text stays readable.
