Each row of the palette now starts with a small picture that says what the row is: a window, a program, a command, an export of a module, a setting, or an act that stops something. A reader tells a window from a program before the reader reads a word. The word of the kind stays at the right of the row, so no picture stands alone. The color of the picture says one fact. A program that has a window is green, and a program that has none is dim. The window that has the focus is blue. The value of a setting that the machine uses is in the color of the text. On the chosen row the picture is white, as the text is. Each picture is a grid of 12 by 12 square cells, drawn as whole pixels: it has no curve and no blur. The pictures are one table of the system. The site draws the same table for its kinds of values, so a module or a command has one picture on the site and on the desktop.
