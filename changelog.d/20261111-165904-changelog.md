**The changelog**: `CHANGELOG.md` lists what each release of the system brings, from the first milestone (0.0.0) to step 58 (0.58.0). A branch adds one fragment in `changelog.d/` for each change; `kerneltool changelog new`, `check`, `assemble`, `release` and `notes` write, check and release them, and `kerneltool release_number` prints the release number.
