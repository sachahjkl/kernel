**A program sets the weight and the request of a thread that runs**: `Thread_Control` has two new commands, `Read_Schedule` and `Write_Schedule`, with the record `Thread_Schedule` (weight, request, weight limit). A program writes the schedule of its own threads; a thread handle reads with Inspect and writes with Control; the machine handle with Schedule names any thread by its machine number, which the thread report now gives (`Thread_Report.machine_number`; the record grows from 72 to 80 bytes), and it alone writes the weight limit of a thread: the thread and the threads that it creates then stay at or under that weight. `Thread_Create` refuses a weight above the weight limit of the calling thread. The kernel still has 33 operations, and a write keeps what a thread owes, so no write raises a share.
