**The kernel records its own work for a program that has the grant**: a program with the new right Events on the machine gives the kernel a table of up to 16 rules (`Events_Set`, the 32nd operation of the kernel). The kernel then writes one 64-byte record into a ring for each processor for each operation of a kernel entry, switch of threads, fault or wait for a kernel lock that a rule accepts, filtered by program, detail, least duration or one in N. A full ring counts the records that it loses, and the table ends with the program that gave it. With no rule, each event point costs one branch. The program `kernel_events` checks the exact counts.
