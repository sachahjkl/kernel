type: Added

**The types of the site have a card**: the new reference page Types shows each type of the contract, each wire form of the module contract, each record of a module and the basic types, with the size, the alignment, the fields with their offsets and padding, or the members with their values, all from the compiler. Each type in a signature, a fact or a table of the reference opens its short card with a click, a tap, the keyboard or a pointer that rests on it.
