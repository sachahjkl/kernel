type: Changed

**The palette replaces the launcher**: the key super opens one panel that lists the programs and the windows in one ranked list, with the fuzzy match of the console and each matched character marked. Enter starts the chosen program or brings the chosen window to the front; the close of a window asks for a second Enter. The input band is the top of the panel, flush with its top, left and right edges, and the typed part is at twice the size of the font. The pointer chooses and runs a row too. The commands of the console are in the list too: a command with no parameter runs from the panel, which shows an Integer, a Text of one line, a Record or an error, and a Table brings the console to the front; a command with parameters opens in the edit line of the console; `shutdown`, `lock` and `history_clear` ask for a second Enter. The console has a new grant, `palette`: `revoke("console", "palette")` leaves the programs and the windows in the palette. The field `launcher` of `compositor.pointer()` is now `palette`, the state of the panel as a number, and the hint of the bar is "palette: super".
