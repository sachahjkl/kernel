**One source library for a program of a third party**: everything that becomes the system is in the folder `src`, and the code that the programs share is one source library, `modus`, in `src/library`. A source imports a package by one name, `import "modus:support/system"` or `import "modus:contract/ring"`, in place of `"support:system"` and `"contract:ring"`, and the compiler gets one flag, `-collection:modus=src/library`, in place of two. A program outside the repository writes the same import lines and gives the same flag. The kernel gets the same library as a program, so the tool, not the compiler, now refuses an import of a support package in the kernel or in a contract package: each build stops on it with the file and the line, and `kerneltool library-imports` runs that check alone.
